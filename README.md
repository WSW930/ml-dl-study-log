# ML/DL Study Log

Computer Vision 분야를 목표로 공부하며 작성한  
머신러닝, 딥러닝, 이미지 분류 및 프로젝트 코드를 정리하는 저장소입니다.

## Learning Roadmap

1. **Basic Step**
   - 혼자 공부하는 머신러닝+딥러닝 기반 학습
   - 머신러닝 및 딥러닝 기본 모델 실습
   - 데이터 전처리, 특성 공학, 모델 평가

2. **Intermediate Step**
   - Stanford CS231N 기반 Computer Vision 학습
   - 이미지 분류
   - Linear Classifier
   - Neural Network 및 CNN

3. **Project Step**
   - Computer Vision 개인 프로젝트
   - 데이터 수집 및 전처리
   - 모델 설계, 학습, 평가 및 결과 분석

4. **Advanced Step**
   - 심화 모델 & 논문 학습
   - 논문 구현 및 재현 실험
   - 모델 개선 및 성능 비교
