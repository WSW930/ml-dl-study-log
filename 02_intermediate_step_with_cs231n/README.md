→ 코드 구현 & 첨삭 과정에서 AI Tool(Codex & Gemini)의 피드백을 활용합니다. 그러나 학습자가 코드를 스스로 이해하기 위해, 중요한 코드 라인은 직접 다시 작성해보고, 이해한 바를 학습용 주석으로 남기면서 학습 중입니다.
